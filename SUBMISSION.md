# Submission checklist

- [ ] Concise project summary
- [ ] Install and run instructions
- [ ] What is implemented and what is mocked
- [ ] Architecture diagram or explanation
- [ ] Five-minute demo path
- [ ] Evaluation results, including one failure case
- [ ] Known limitations and next steps
- [ ] Estimated cost and usage information
- [ ] Most interesting `session.jsonl`, if available
- [ ] Short note on AI coding tool use

Do not include credentials, private Brainforge data, or personal data in the repository or logs.
